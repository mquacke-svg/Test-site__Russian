# Контекст PHP-версии «Жак-Андрэ»

Актуальная опубликованная реализация на 31.10.2026: HTML/CSS, PHP 8.3, SQLite и небольшой обычный JavaScript. Сайт использует формы с перезагрузкой; для работы Node.js не нужен. Сохранены дизайн, маршруты, каталог, корзины, заказы, кабинет, админка и совместимость паролей прежней версии. VK/Google/Telegram удалены; платежи и передача заказов в пекарню не подключены.

Регистрация — по логину и непустому паролю до 128 символов. Точное количество остатков показывается только сотруднику. Рабочая база, аккаунты, секреты, сессии и файлы хостинга не включены в Git. Тесты — на отдельных базах.

Результаты повторной проверки — `BROWSER_QA.md`; запуск и требования к данным — `README.md`; объяснение устройства — `docs/DEFENSE.md`.
