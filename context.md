# Контекст проекта «Жак-Андрэ»

Русскоязычный сайт пекарни на Next.js, React, TypeScript и SQLite. Корзины гостей и пользователей и заказы хранятся в базе; количество товара настраивается в админке и уменьшается при заказе. Гостевая корзина объединяется с корзиной пользователя при входе.

Для регистрации покупателя используются email, пароль от 8 символов и подтверждение электронной почты. Доставка писем настраивается через SMTP, учётные данные хранятся вне репозитория. Администратор создаётся командой `npm run admin:create`.

В каталоге карточки товаров выровнены; оформление использует шалфейно-зелёную палитру. На странице регистрации ссылки входа и продолжения покупок расположены на отдельных строках.

Сборка: `npm run build`. Серверные тесты: `npm test`. Переменные окружения перечислены в `.env.example`; локальные данные и загруженные изображения не включаются в Git.

Проверки при подготовке репозитория: сборка успешно выполнена, 25 серверных тестов прошли. Сайт опубликован на Beget; работа реальных заказов, платежей и доставка писем во внешние почтовые сервисы требуют отдельной проверки.
