# Размещение PHP-версии

Сайт работает на PHP 8.3 с расширениями из README. Единственный открытый веб-каталог — `public/`; `lib/`, `views/`, конфигурация, SQLite, uploads и сессии размещаются вне него. Node.js не требуется для выполнения приложения.

Задайте `APP_URL`, `DATABASE_PATH`, `UPLOADS_PATH`, `SESSION_PATH`, `BACKUP_PATH` через окружение либо закрытый `.local/config.php`. База должна быть совместима с прежним магазином; `setup.php` проверяет её и готовит служебную таблицу, не заменяя каталог. Данные и секреты передаются владельцем отдельно от Git.

Перед переключением версии сохраните согласованную резервную копию базы и фотографий, повторите проверки на отдельной копии данных, проверьте HTTPS и изображения. Не запускайте тесты или seed на рабочей базе. Подробности команд backup/restore и их ограничения — в README.

Для отката кода сохраняйте предыдущий каталог версии и конфигурацию веб-сервера. При откате используйте актуальные SQLite и uploads, чтобы не потерять новые заказы. Старую резервную копию данных не следует использовать для обычного отката кода. После смены реализации может потребоваться повторный вход.
