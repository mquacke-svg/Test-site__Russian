# Как объяснить сайт на защите

Сайт состоит из страниц, серверной программы и базы данных. Браузер показывает страницы, PHP обрабатывает действия посетителя, SQLite хранит результат.

| Средство | Назначение |
|---|---|
| HTML | Заголовки, карточки товаров, изображения, формы |
| CSS | Цвета, шрифты, расположение, мобильная версия |
| JavaScript | Меню, фильтры и небольшие удобства интерфейса |
| PHP | Вход, корзина, заказы, административные действия |
| SQLite | Товары, пользователи, корзины и история заказов |

**Открытие каталога:** браузер запрашивает страницу → PHP читает товары через PDO → подставляет данные в HTML-шаблон → браузер показывает готовую страницу с CSS.

**Вход:** посетитель отправляет логин и пароль → сервер сравнивает пароль с сохранённым хешем → создаёт сессию → браузер получает cookie с её идентификатором. Сам пароль в cookie не записывается. В этом проекте используется scrypt, чтобы старые аккаунты работали после переноса.

**Корзина:** cookie позволяет найти гостевую корзину в SQLite. После входа гостевая корзина объединяется с корзиной аккаунта. Состав корзины и цены не доверяются данным браузера.

**Заказ:** PHP заново проверяет цены и остатки, вычисляет стоимость доставки, записывает заказ и уменьшает остатки. Эти действия входят в одну транзакцию: либо сохраняются вместе, либо отменяются при ошибке. Повторная отправка той же попытки возвращает существующий заказ.

**Админка:** сервер проверяет роль пользователя перед каждым изменением. Сотрудник управляет товарами, фотографиями, доставкой, остатками и статусами заказов. Покупатель видит доступность, точные остатки доступны сотруднику.

**Защита данных:** PDO подставляет значения отдельно от SQL; выводимый текст экранируется; формы используют CSRF-токен. База, настройки и файлы сессий находятся вне открытого веб-каталога.

**Что показывать:** главную → фильтр меню → добавление товара → корзину → вход → оформление → заказ в кабинете → тот же заказ в админке → изменение статуса. Затем показать один шаблон, одну функцию работы с базой и таблицы SQLite.

Проект не включает онлайн-оплату, VK/Google и Telegram. Резервные копии и тесты проверяют сохранность данных и работу реализованных сценариев.
