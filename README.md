# MIRAI 未来 — туры в Японию

Концепт-сайт туристической компании в стиле голографического интерфейса: стеклянные панели с угловыми скобками, свечение, скан-линии, переливающиеся заголовки.

## Что есть на странице

- **Загрузка**: экран «инициализации голограммы» (показывается один раз за сессию, по нажатию пропускается).
- **Первый экран**: вращающаяся 3D-голограмма Японии из тысяч точек поверх видео Kling с Фудзи. Её можно повернуть пальцем или мышью. Фудзи поднимается пиком, города светятся столбами света, по карте проходит сканирующая линия, а подписи главных городов открывают туры. Рядом терминал «MIRAI OS», живые часы Токио (JST) и расшифровка заголовка. Касание пустого места вызывает всплеск частиц текущего сезона.
- **Курсор-прицел** с координатами на компьютере.
- **Голограмма 360°** (`hologram.html`): отдельная страница, где модель Японии можно рассмотреть со всех сторон. Её можно вращать в любом направлении, в том числе снизу, приближать колесом или двумя пальцами и выбирать готовые ракурсы («Сверху», «С юга», «С востока», «С севера», «С запада», «Снизу»). Нажатие на город приближает камеру к нему и показывает карточку. Слои (суша, берег, сетка, кольца, столбы, сканирование), высоту рельефа и цвет голограммы можно менять. Клавиши: стрелки поворачивают, `+`/`−` приближают, `1`–`7` переключают ракурсы, `R` сбрасывает вид, пробел включает автоповорот.
- **Туры**: 4 карточки с видео Kling. На компьютере видео включается при наведении, на телефоне при прокрутке. Карточка наклоняется за курсором, а по нажатию открывается программа по дням.
- **Конструктор маршрута**: точечная карта Японии (контур Natural Earth) на наклонённом «голографическом столе», с врезкой Окинавы. Можно нажимать города, менять число ночей и выбирать готовые маршруты. Сайт считает время в пути, расстояние и ориентировочную стоимость и подсказывает, выгоден ли JR Pass.
- **Сезоны**: весна, лето, осень и зима перекрашивают весь сайт круговой волной и меняют частицы (сакура, светлячки, клёны, снег). Для каждого сезона есть календарь: сакура-фронт, мацури, момидзи-фронт.
- **Заявка**: форма собирает посадочный талон в реальном времени, с транслитерацией имени как в загранпаспорте, местом, выходом, кодом брони и штрихкодом.
- **Быстрый поиск**: клавиша `/` или `Ctrl/⌘ + K`.
- **Звук**: кнопка с эквалайзером включает звуки интерфейса в японском ладу ин (мияко-буси).
- Учитывается настройка «уменьшить движение» (`prefers-reduced-motion`).

## Структура

```
index.html            разметка
hologram.html         полноэкранный просмотр голограммы (стили и код внутри файла)
css/style.css         стили, палитра и сезонные акценты
js/app.js             весь интерактив, данные туров, городов и сезонов
js/japan-outline.js   упрощённый контур Японии
media/                видео Kling и кадры-обложки к ним
```

Видео сгенерированы в Kling 3.0 Turbo через Higgsfield, звук из них убран, а конец каждого ролика плавно перетекает в начало, чтобы цикл шёл без рывка. Всего медиафайлов на 1,9 МБ.

## Как запустить

Откройте `index.html` в браузере или запустите локальный сервер:

```
python3 -m http.server 8000
```

Чтобы опубликовать сайт через GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**.

## Где менять содержимое

Туры, города на карте, готовые маршруты и сезонные календари лежат в начале `js/app.js`, в массивах `TOURS`, `CITIES`, `PRESETS` и `SEASONS`.

Цены, даты и рейсы на сайте приведены для примера. Форма заявки работает в демо-режиме и никуда не отправляет данные.
